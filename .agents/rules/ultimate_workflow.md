# Ultimate Multi-Agent Workflow Guidelines

## 1. Roo Code & Ralph Loop Layer (Context & Iteration)
- Maintain an unbroken execution tracking loop (Ralph Loop) for every task assigned.
- Auto-analyze the code structure and gather file context precisely before writing any code changes.
- Never modify files blindly; generate discrete, targeted diff blocks.
- Perform root-cause analysis before editing CSS or JavaScript to avoid regression.

## 2. Get Shit Done (GSD Layer - Aggressive Execution)
- Prioritize compiling working software, running automated test assertions, and rapid deployments.
- Output clear, concise steps and proactively execute verification scripts.
- If a test suite fails, automatically backtrack one execution step and fix the code break immediately.
- Never stop at theoretical solutions; execute and verify with live builds and automated checks.

## 3. CodeRabbit Layer (Pull Request & Code Integrity Alignment)
- Structure all code formatting, docstrings, and commit messages to satisfy strict, automated PR review line checks.
- Keep components modular, CSS cleanly separated, and avoid duplicate or dead code.
- Ensure all interactive elements have accessible labels, high-contrast visibility, and proper keyboard navigation.
